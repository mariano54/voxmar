// Voxmar's pixel font: every menu, the HUD and the console write with it.
//
// Each glyph is `= c` and its rows, `#` for ink and `.` for paper. The first row is the top
// of a capital letter, seven rows above the baseline; lower case starts two rows lower,
// and descenders go two rows below the baseline. Glyphs are as wide as their rows and get
// one pixel of space after them. Accented letters are composed from a letter and a mark
// (see the end), so a mark is drawn once. The game turns this file into a TrueType font
// when it starts (`voxmar_texgen::font`), so editing it is all it takes to change the font.
